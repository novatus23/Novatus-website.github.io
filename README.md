# E-Commerce Website for Electronic Equipment  

## Overview  
This is a simple e-commerce website for selling computers, mobile phones, and other electronics.  

## Features  
- Product catalog  
- Shopping cart  
- Checkout system  

## Setup  
1. Clone the repository:
2. Create a database named `ecommerce` and import `database.sql`.  
3. Update `db.php` with database credentials.  
4. Run the project on a local server using XAMPP or MAMP.
